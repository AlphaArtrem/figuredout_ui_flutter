## Where a new finding goes

- A component shipped, removed or changed its API: `CHANGELOG.md`, plus `README.md`,
  `components.md` and the manifest (see `AGENTS.md`, Working Style).
- The current state or the next action changed: edit `state.md` in place.
- A phase started, finished or was re-scoped: `plan.md`.
- A version, SDK constraint or third-party behaviour was checked: `external-facts.md`.
- Something actually broke: add it to `AGENTS.md` "Things That Have Already Bitten Us", and
  delete the matching prediction from `state.md` if there was one.
